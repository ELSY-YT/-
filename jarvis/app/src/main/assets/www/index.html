Разрешения

Если «Спец. возможности» не дают включить Джарвиса (Android 13+), открой «О приложении» → ⋮ → «Разрешить ограниченные настройки», потом включи снова.

Голос

🎩 Обращаться «сэр»
Нужен свой голос? Поставь любой TTS-движок для Android (например, RHVoice), выбери его здесь, и Джарвис будет говорить им.

Быстрый вызов

Опусти шторку → ✏️ изменить плитки → перетащи плитку «Джарвис». Нажатие сразу включает микрофон. Ещё можно долго нажать кнопку на гарнитуре.
