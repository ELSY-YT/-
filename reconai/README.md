# ReconAI для Android (APK)

Отдельное приложение: ИИ работает прямо в телефоне через llama.cpp, без Termux и без Ollama.
Внутри та же модель, что и в Termux-версии: huihui-ai Qwen2.5 abliterated 1.5b. Параметры те же: контекст 2048, 6 последних сообщений, результаты инструментов обрезаются до 1500 символов, не больше 6 шагов.

## Сборка на ПК друга (Android Studio)
1. Установить Android Studio (бесплатно, developer.android.com/studio).
2. Распаковать архив и открыть папку `reconai_android`: File → Open.
3. Подождать, пока Gradle всё скачает. В первый раз это 10–20 минут: подтянутся NDK 29, CMake 3.31.6 и исходники llama.cpp. Если Studio попросит установить NDK или CMake, жмите Install.
4. Build → Build App Bundle(s) / APK(s) → Build APK(s).
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Из терминала можно так: `gradlew assembleRelease`, тогда файл будет в `app/build/outputs/apk/release/`.
5. Перекинуть APK на телефон и установить. Android попросит разрешить установку из неизвестных источников.

Сборка без ПК: залейте папку в свой репозиторий на GitHub. Вкладка Actions сама соберёт APK по файлу `.github/workflows/build.yml`, готовый файл будет в артефакте «ReconAI-apk».

## Первый запуск
1. Зарегистрируйтесь. Аккаунты хранятся только на телефоне.
2. ⚙️ Настройки → «Модель в телефоне» → пресет «Телефон 4 ГБ: 1.5b» → ⬇️ Скачать. Нужно около 1 ГБ, загрузка с Hugging Face докачивается после обрыва.
   Если файл .gguf уже есть, например скачан для PocketPal, жмите «📁 Выбрать .gguf».
3. Вкладка 🤖 Агент. Первый вопрос думает дольше: модель загружается в память.

## Что внутри
- Вкладки те же: Агент, ⚡ Быстрая разведка, Утилиты, Фото (EXIF/GPS), Сервисы, Настройки.
- Утилиты переписаны на Kotlin. DNS идёт через DNS-over-HTTPS (Cloudflare). WHOIS работает по порту 43 через IANA, поэтому .ru тоже поддерживается. Ещё есть crt.sh, ipwho.is, заголовки, Wayback, поиск DuckDuckGo и открытие страниц.
- Режим «Ollama на ПК или в Termux»: в настройках укажите адрес, например http://192.168.1.10:11434. На ПК запускать так: `OLLAMA_HOST=0.0.0.0 ollama serve`. Тогда на телефоне можно взять модель 7b.
- Сервер интерфейса слушает только 127.0.0.1:8766, снаружи телефона к нему не подключиться.

## Если что-то не так
- Вылетает при первом вопросе, значит не хватает памяти. Закройте другие приложения, поставьте контекст 1024 или скачайте пресет 0.5b.
- Медленно: выставьте «Потоки процессора» 4. Больше 4 на слабых телефонах обычно только медленнее.
- Агент не вызывает инструменты: для 1.5b это нормально, пользуйтесь «⚡ Быстрой разведкой» и вкладкой «Утилиты».
- Нужен 64-битный Android 8.0 или новее.
